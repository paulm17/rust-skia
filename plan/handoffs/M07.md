### Adaptation notes

- **Ownership.** `SkPath` holds `Arc<SkPathData>` + fill type + volatile flag, reproducing `SkRefCnt` copy-on-write. `SkContourMeasureIter::next` returns `Option<Arc<SkContourMeasure>>`; `SkPathMeasure` keeps `Option<Arc<SkContourMeasure>>`.
- **`SkPathRaw`.** C++ is a non-owning view over caller storage; the Rust port owns `Vec`s (self-referential stack shapes cannot be expressed safely). The observable API (`points`, `verbs`, `conics`, `bounds`, `is_rect`) is preserved.
- **`SkPathEdgeIter`.** Yields an owned `[Point; 4]` plus valid length instead of pointers into path storage. Observable verb/point sequence is unchanged.
- **`PerspectiveClip`** is fully implemented: half-plane normalization, `test()` on bounds, rotation by the half-plane matrix, `SkEdgeClipper::clip_path` against `{-MAX, 0, MAX, MAX}`, result re-transformed by the rotation matrix, and an empty path when clipped out or non-finite. `SkPathBuilder::transform` (perspective branch) was updated to use it; the previous “M07 DEFERRED” fallback is gone.
- **`detach` / `snapshot`** in the reference return `std::optional<SkPath>`; the Rust builder returns `SkPath` and `detach(None/Some(&Matrix))` is total. Empty input yields the empty path, matching the C++ empty optional's consumed-builder effect.
- **`SkContourMeasureIter::reset`** takes `&SkPath`; `SkPathMeasure::set_path` takes `Option<&SkPath>` (`None` = the C++ `nullptr`/default-path behavior).
- **`SkPathMeasure::from_path(path, force_closed, res_scale)`** is the Rust spelling of the C++ constructor; `SkPathMeasure::new()` is the default constructor.
- **Constant names** are preserved for numeric behavior: `K_MAX_T_VALUE` (`0x3FFFFFFF`), `KW0_PLANE_DISTANCE`, segment masks. C++ bitfields (`fTValue:30`, `fType:2`) are stored as full `u32`/enum fields; the observable values are identical.
- **`SkString` formatting** for `ToSVGString` reuses `SkStrAppendScalar` semantics (`nan`/`inf`/`-inf`, otherwise `%.8g`) routed through the project's existing libc-backed formatter, so the text is byte-identical.
- **Arcs in `ToSVGString`** use `SkAutoConicToQuads` with the reference tolerance `1/1024`, emitting one `Q` per quad; the conic weight is fed from the iterator record.
- **Float evaluation order** is preserved verbatim (including `(a/2 + c/2)/2` in `quad_too_curvy`, `1/3` and `2/3` cubic checks, and the `distance += d` “did it grow?” guards in the contour segment drivers).
