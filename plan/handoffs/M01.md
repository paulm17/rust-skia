- `tests/UPSTREAM.md` is stale relative to the current implementation (it describes the pre-M01 library bodies as unreviewed/unchanged). It is Codex-owned and was intentionally not edited.
- Deferred branches and explicit adaptations:
  - Windows/MSVC NaN handling, MSVC pragmas, `SK_NO_SANITIZE`, and `SK_BUILD_FOR_WIN` branches in `SkFloatingPoint.h` are excluded on macOS.
  - The 32-bit `skvx` `SkRect::Bounds` branch is excluded; the 64-bit reference branch is implemented.
  - Full `SkMath.h`, `SkSafe32.h`, and `SkTo.h` remain M03. The small `SkMath`/`SkSafe32` subsets above are real prerequisites implemented early so that `IPoint` saturating arithmetic and `SkLeftShift` semantics match the pinned sources.
  - `SkAPI.h`, `SkAssert.h`, `SkAttributes.h`, `SkDebug.h`, and `SkTypes.h` remain M02.
  - Full `SkRect` remains M04/M07/M14; only the minimal Scalar/Point slice is implemented.
  - `float_interp_func` returns `0.0` for empty input and uses the shorter input length for mismatched lengths; `scalars_equal_n` panics if `n` exceeds the slice length; `are_finite` and `is_finite_slice` return `true` for empty inputs. These are defined Rust adaptations where the C++ source has undefined behavior or caller preconditions.
  - `IPoint` unary negation uses wrapping negation on `i32::MIN`; no-saturate casts use Rust's saturating cast behavior. Both are defined-language adaptations of C++ undefined behavior.
  - `Point::Normalize` is `normalize_returning_length`; `SkPoint::Offset` overloads are `offset_all` and `offset_all_by`; `scale` overloads are `scale` and `scale_in_place`; `iset(const SkIPoint&)` is `iset_ipoint`; `Side*` output parameters are `Option<&mut Side>`.
  - `SetLengthFast` delegates to the slow path; this is behaviorally identical because the C++ template flag only affects an assertion.
  - `set_rect_fan`, `set_rect_tri_strip`, and `set_rect_tri_strip_rect` are `unsafe` raw-pointer/stride APIs with documented safety contracts.
  - `make_orthog` accepts `Side`; release-mode `Side::On` falls through to the left branch, matching the C++ expression structure.
  - `-0.0` maps to `+0.0` in the 2s-complement conversion, matching the reference conversion path; bit-level round-trip checks exclude that case.
