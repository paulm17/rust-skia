### Production failures fixed

- MD5 incremental writes now retain and process partial 64-byte blocks, including one-byte-at-a-time input.
- UTF-8/UTF-16 counts return signed counts and reject invalid/truncated input; UTF-8 encoding rejects code points above `0x10FFFF`.
- `AutoTArray`/`AutoSTArray` writable default construction and `AutoReallocToZero` semantics fixed.
- `SkBlockAllocator` rewritten for contiguous raw block allocation, exact growth/prealloc/scratch/owning-block arithmetic, metadata, and release behavior; all 14 block tests and 8 supplemental tests pass.
- Arena external-storage support; `SkData` borrowed no-copy identity, empty release-proc handling, and no-copy subset behavior fixed.
- `SkStream` packed-uint reads reject every short/truncated input exactly; checksum vectors and Murmur/wyhash behavior fixed; resource-cache checksum call updated.
- `SkString::contains("")` now returns true, `find("")` returns index 0, and `append_scalar(f32)` uses C++ `SkStrAppendScalar` (`"nan"`, `"inf"`, `"-inf"`, otherwise `%.8g` with no `f` suffix and 15-byte maximum).
- `AutoTArray`/`AutoSTArray` expose null `get`/`data`/`data_mut` whenever empty, including zero construction, `reset(0)`, and moved-empty containers.

### API surface added for the reported gaps

- `SkTCopyOnFirstWrite: Clone`; `THashMap`/`THashSet: Clone`; `THashSet::{find,reserve,approx_bytes_used}` with exact `(size_of::<T>() + 4) * capacity`; Skia-compatible reserve and single-step shrink hysteresis.
- `SkTDeque::with_capacity`; default block capacity is now 1. `TInternalLList::{iter,iter_rev,head_handle,tail_handle}` plus exported iterator types.
- `RawPtr: Ord + Hash`; `SkString::{append_s64,append_u64}(value,min_digits)` and `Hash`.
- `AutoTArray`/`AutoSTArray`: `reset(count)`, no-arg `clear()`, `size`, `with_count`, `data_mut`, `trim_to`.
- `TBlockList::concat<const M>` and reserve/scratch accounting fields; pointer stability retained.
- `THashTable<V,K>` key/value contract with `set`, `find`, `find_or_null`, `remove`, `reserve`, `reset`, `iter`, and capacity/bytes accounting.
- Functional and callback executor factories now create real background pools: FIFO/LIFO work selection, priority work lists (0 highest), configurable worker count, borrowing, pending/wait/shutdown, and clean join-on-drop. `SkTaskGroup` supports local mode plus `with_executor`/`new_with_executor`; one-argument `add` remains for existing tests and `add_priority(f, work_list)` supplies priorities. `SkCallbackExecutor`, `SkExecutorCallbackWork`, and non-generic `SkCallbackExecutors` are exported.
- `RefCnt` is dyn-compatible. `SkSp<T: ?Sized + RefCnt>` is exactly one pointer (8 bytes) using a small heap erasure header, so `SkSp<dyn Trait>` owns and drops correctly without inflating sized handles. The header separately stores the concrete owner pointer and the exposed view pointer, so `SkSp::cast`/`clone_as` preserve nonzero-offset base projections without misusing the projected address for refcount/disposal. `sk_make_sp(value)` retains concrete inference; `sk_make_sp_as::<U, _>(value)` requires the concrete owner `T: Send + Sync`, preventing a sized `SkSp<Target>` from hiding an unrelated `Rc`-bearing owner and satisfying the sized/unsized compile-negative contracts.
