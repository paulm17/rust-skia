### Shared-file and prerequisite notes

- `src/rect_priv.rs` retains all M04 helpers. The M05 quad-containment functions build on `Rect`, `IRect`, `M44`, and `Matrix`; they do not replace M04 subtraction/closest-edge behavior.
- `src/lib.rs` exposes the new modules and selective root re-exports: `M44`, `SkM44`, `V2`–`V4`/`SkV2`–`SkV4`, `Matrix`, `SkMatrix`, all `K_*` masks (including `K_ALL_MASKS`), invert/Givens/decomposition helpers, `RSXform`, `SkRSXform`, and `MAX_FLATTEN_SIZE`. Module-level access remains available for constants and private helpers.
- `Matrix::new()`/`SkMatrix::I()` use the type mask `K_RECT_STAYS_RECT_MASK` internally, so identity reports `getType() == 0` while `rectStaysRect()` remains true, matching the reference cache semantics.
- `Matrix` and `M44` layouts are `#[repr(C)]`; `Matrix` is nine scalars plus the cached `u32` mask, and `M44` is sixteen scalars. `M44` storage is column-major. `SkM44(const SkMatrix&)` conversion is implemented through the same row-major expansion as the reference.
- Per the contract, all logic is in Rust. No external Skia port, native Skia library, ignored test, or unreachable placeholder implementation was added.
