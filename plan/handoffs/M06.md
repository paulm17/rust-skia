### Shared-file and prerequisite notes

- `src/lib.rs` registers the eleven new modules and root re-exports. No Cargo feature or dependency was added.
- Existing M01–M05 types are reused unchanged: `Point`/`Vector` (`Add/Sub/Mul`, dot/cross/length), `Rect` (`bounds_or_empty`, `center_x`, `center_y`), `IRect`, `Matrix` (`set_sin_cos`, `pre_scale`, `post_concat`, `map_points_in_place`, `map_homogeneous_points`, `has_perspective`), `Point3`, `PointPriv`, and the `floating_point`/`scalar` helper families. No earlier behavior was modified.
- Two path-owned declarations are introduced early because M06 public signatures consume them: `SkPathDirection` (`Cw`/`Ccw`, in `src/sk_geometry.rs`) and `SkPathVerb` (in `src/sk_edge_clipper.rs`). M07 adopts both unchanged; `SkPathVerb` already uses the reference discriminants.
- `skvx::float2`/`float4` arithmetic is replaced by scalar `Point`/`[Scalar; 4]` operations. Every site keeps the reference expression order, including the two-lane cubic chop and the four-lane midtangent coefficient accumulation; `skvx::fma` maps to `f32::mul_add`, `std::fma` to `f64::mul_add`.
- The `SkConic` public fields remain `pts: [Point; 3]` and `w: Scalar` with the `set_w` guard (`w > 0 && finite`, else 1), so caller-visible layout/order matches the reference value semantics.
- `SkAutoConicToQuads` owns a `Vec<Point>` instead of `AutoSTMalloc`; `compute_quads` returns a borrowed slice into that storage and `count_quads` reports the quad count.
