## Coverage and discovery

The unchanged C++ M02 sources compile, discover **110 enabled CPU registrations**, and pass all 110 in **both debug and release**. There are no additional registrations. The static inventory has 111 sites; `RawPtr_DanglingPointerDetected` is absent in both actual registries because `SK_USE_PARTITION_ALLOC` is undefined. Its nested dangling-check guard is also required. It is NOT_APPLICABLE, never an executed PASS. The other 14 RawPtr sites are enabled in C++.

Rust executes **90 original registrations**. Debug: **79 PASS, 11 FAIL**. Release: **81 PASS, 9 FAIL**. **Twenty additional applicable registrations remain unexecuted owing to required API gaps; they are not passes, skips, or completed translations.** The complete `TCopyOnFirstWrite_copy` body is retained as a compile-failing test; other API probes are minimal diagnostics, not substitutes for complete original bodies. Translation/execution of those bodies and their helpers must be completed after Deepseek supplies the missing contracts. This report does not claim that all 111 translations are finished.

The [111-row correspondence ledger](M02-evidence/correspondence.csv) records source location/hash, Rust mapping or exact gap, both profiles, reference results and adaptation/exclusion reasons. ### Translated bodies and helper/fixture handling

- `tests/m02_test.rs` includes translations under `tests/m02/`. Reporter assertions remain nonfatal and evaluate once; unexpected production panics terminate the individual case. Original inputs, loops and expected values are retained for the 90 executable bodies. No tolerance was relaxed and no failing assertion was removed. All individual cases run again in separate processes to obtain unmixed diagnostics and prevent a crash/hang from hiding later cases.
- Arena construction/destruction counters use per-case shared cells instead of C++ function statics; Foo construction closures preserve distinct default constructions. Stack and supplied-storage constructors are exercised. Placement-new destruction traversal uses unregistered arena storage and explicit recursive traversal; blocks remain live throughout. Rust raw pointers represent the original observable addresses.
- Block allocator helpers retain allocation sizes, alignment/padding, all four growth policies, release/reset/steal ordering, scratch accounting, and all 9 padding × 8 alignment owning-block combinations. `sizeof(SkBlockAllocator)` maps to the Rust type's native size, preserving the original self-layout observation rather than replacing it with the implementation's unrelated constant. Iteration-and-release snapshots original block pointer order before releases to satisfy borrowing; it does not replace allocator operations.
- Data tests retain subsets, pointer-vs-content observations, all 6 × 6 empty comparisons, typed and variable data tables, and the alphabet temporary-file fixture. The FD stays owned by the test. Raw allocation/C-string/null-pointer factories adapt to Rust-owned storage and closures; those adaptations do not establish no-copy/release parity, which separate reference-backed checks disprove. File-path adaptation to MakeFromFILE does not claim equivalent cursor/mmap behavior.
- UTF fixtures preserve all 23 count cases, 11 valid UTF-8 cases, five non-BMP UTF-16 values, and six decode/encode cases, including both invalid `-1` values. Encoding uses a four-byte array view inside the original five-byte zeroed sentinel buffer. Negative expected counts are compared as signed integers; zero is not reinterpreted as the required `-1`.
- All seven RFC1321 MD5 messages run both whole-buffer and byte-at-a-time paths. C++ initializer-list map construction is represented by inserting the same ordered entries; the original post-construction capacity/search assertions remain, without claiming a separate Rust initializer-list API. String overflow/VAList cases retain widths 2000/1999 and every space assertion; formatting arguments use `SkFormatArg`. The `String_huge` manual crash loop retains its original `false` guard, recorded as a body that executes zero assertions, not large-allocation validation. All original split fixtures and resize assertions remain.
- Span mutability is expressed by `SkSpanMut`; immutable borrows end and views are recreated around the original backing-store mutation where Rust forbids the C++ alias pattern. Pointer/address comparisons use production RawPtr/SkSp operations. C++ moved-from null observations use the handoff's explicit `take()` adaptation. Base/derived raw pointers use `repr(C)` prefix structs, without dereferencing a freed allocation.
- LRU instances/destructors and move-only keys retain original observations. MessageBus tests retain original messages, ordering, inbox polling and unique ownership. A per-case explicit bus replaces static-per-message-type state because each original registry case runs in isolation. Immutable string-view fixtures map to `&str`; owning strings remain `SkString`.
- `IncrTopoSort` includes the original test-local Node/Graph, DFS/shift algorithm, validation calls and four graph fixtures. It still uses production `SkTArray`, `SkTDArray`, sorting, strings and intrusive references. `MetaData` includes reached type/name lookup, head insertion, same-size update, iteration and removal support from `tools/SkMetaData.*`; it tests Codex-owned tool support and is not production coverage.
- `RefCnt` uses real native threads, preserving 100000-iteration strong/weak loops. `SkOnce_Multithreaded` retains 1021 task-group submissions; shared-mutex tests retain 8 tasks × 100000 iterations and all **5,400,000** reader assertions. Atomic shared cells avoid undefined behavior if synchronization fails; reporter access is synchronized. The production task group runs synchronously, so these PASS results do **not** prove executor concurrency. Both original executor registrations remain failed API obligations.
- None of these assigned original bodies uses `SkRandom`, `FakeStreams.h` or `tools/Resources.*`; no RNG is substituted or required. FakeStreams' three helpers are nevertheless translated for separately labeled stream checks; Resources, Test/CTS support and OWNERS metadata are hashed. No shader/golden/download is required. The alphabet file is created/read locally and removed. Literal fixtures are covered by the reference/test hashes.

## Gate decision and remaining work

**NEEDS_FIX** follows actual behavior/API failures, not a missing SDK, resource, external service or backend device. M01 remains ACCEPTED. M03 stays NOT_STARTED. `plan/status.json` points here, and only M02 registration inventory rows receive new results.

Deepseek must fix the reported production contracts and provide faithful Rust interfaces for the twenty unexecuted registrations. Codex must then finish those complete test bodies/helper closures (including all executor factories, block-list reserve/concat combinations, hash capacity sequences, smart-pointer lifetime/cycle counters and the full String registration), rerun failures and affected tests, reconcile reference discovery again, and repeat cumulative debug/release validation. Handoff-listed approximations, synchronized cache behavior and deferred integration branches remain outstanding at their published gates. The current subset of passing cases, successful builds and clean supporting checks do not establish M02 acceptance.
