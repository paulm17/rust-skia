## Reference comparison

`reference/ref_as_a_dash.cpp` (built from the pinned sources by `reference/build.sh`) and a temporary Rust probe with identical inputs (source kept as `reference/rust-probe-src.rs.txt`; the probe test file was deleted afterwards, so `tests/` contains only Codex's files) were compared line by line (`reference/as-a-dash-compare.log`, exit 0).

The 18 probes cover the three registrations and their boundaries: corner radius 1/0/NaN/∞/smallest-subnormal; dash intervals `{4,2,1,3}` with phases 2, −7, 27, −10 and −`from_bits(1)`; odd/zero/NaN/∞/overflowing interval sets; NaN/∞ phases; `{0,1}`. The two outputs are **byte-identical (40 lines)**: `valid`/`null`, interval count, every phase bit pattern and every interval bit pattern agree. This independently confirms the literal expectations used by the translations, including `phase(−7) = 3`, `phase(27) = 7` and the tiny-negative-phase rounding to 0.

The handoff's broader development differential (84 `applyToPath` + 21 effect cases, 3 003 dumped lines) is not acceptance evidence; its only recorded deviation is 45 lines of 1–4 ulp float noise in curved-stroke and dash/discrete coordinates. No accepted M08 registration compares geometry, and the AsADash path is bit-exact above. It is carried forward as a known deviation for the M14/M23 geometry gates, where the original tests supply their own tolerances.
