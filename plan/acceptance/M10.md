## Failures for Deepseek

None. Two production defects found during the implementation differential were fixed before acceptance and are recorded here for traceability:

- `classify_into` left its PQ/HLG-ish out-parameters as `None`, panicking `skcms_transfer_function_eval`/`invert`; it now fills them like the reference's non-null pointers.
- 16-bit curve/CLUT sampling byte-swapped values a second time; `SkcmsCurveTable::U16`/`SkcmsGrid::U16` already hold native values, so sampling now uses them directly. This removed every A2B-profile transform difference.

No Rust or C++ registration failed, and no test-source defect required correction.

## Known limits carried with named gates

These are outside every M10 registration and are recorded rather than claimed complete; none weakens an accepted assertion:

- `ABGR_4444`/`ARGB_4444` **store** byte parity: the pinned reference's own store does not round-trip (`0x400b → 0x320b`, reproduced through `out/M09Ref/libskia.a`), so the port writes the declared nibble packing instead. Deprecated format; no registration or fixture uses it. Gate: **M12** (raster-pipeline pixel-format parity).
- `RGBA_hhhh` **premultiplied** conversion: the reference runs half-float formats through an F16 pipeline; the port computes in `f32` and converts once, a one-low-bit difference on 2/1,368 differential lines. Gate: **M12**.
- 10-bit XR inputs outside their valid domain: the reference sign-extends negative intermediates, the port saturates; valid-domain XR is byte-identical (8/8 observations). Gate: **M16/M17**, whose ICC/color-space tests use in-domain data.
- Later-gate integration already listed in the handoff: `SkColorSpaceXformSteps` 8888/raster rows → **M12**; `SkColorTable` `SkBitmap` storage → **M11**; `SkReadBuffer`/flattenable bridges → **M22**; ICC and color-space codec tests → **M16/M17**; color-filter consumers → **M13**; GPU surfaces → **M32–M38**.

## Gate decision

Every assigned M10 registration exists in both the static inventory and the runtime registries, was translated without weakening an assertion, and passes in debug and release in both the Rust port and the unchanged pinned C++ reference. All previously accepted M01–M09 tests remain green (514 total, 0 failures, both profiles). All 28 production/build source rows are mapped to Rust implementations or to a documented macOS-scope disposition; every remaining branch has an explicit later gate and none is presented as complete. The fixture hash matches. Formatting, Clippy and the plan/hash validator pass.

M10 is therefore **ACCEPTED**. `plan/status.json` is updated from this report; M11 remains unopened and is not started.
