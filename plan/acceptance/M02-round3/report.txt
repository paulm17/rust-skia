### 1. Existing-handle base projection is discarded

`tests/m02/supplemental.rs:221–222,229–230`, case `supplemental::supplemental_smart_pointer_projected_base`, fails **four assertions in both profiles**. Expected `.clone_as(|d| &d.base)` and `.cast(|d| &d.base)` to preserve the supplied base address and read value **42**. Actual pointer is the containing object's start (8 bytes before the requested base) and reads **11** from the other valid Base subobject. Debug observed expected `0x14af042b8`, actual `0x14af042b0`; addresses vary by process. Both subobjects are valid initialized Base values; the check avoids invalid memory access and does not synthesize a production conversion.

Production location: `src/ref_cnt.rs:328–341`. `cast` evaluates the projection then discards its result, retaining the old pointee address. `clone_as` delegates to it. This supplemental case extends the base conversion contract reached by `RefCntTest.cpp::sk_sp`; there is **no direct original assertion for a nonzero-offset Rust projection**, so no upstream assertion location is invented. Original single-base prefix conversion observations pass.

Exact reproductions from the Rust repository:

```sh
cargo test --locked --test m02_test supplemental::supplemental_smart_pointer_projected_base -- --exact --nocapture
cargo test --release --locked --test m02_test supplemental::supplemental_smart_pointer_projected_base -- --exact --nocapture
```

Both exit 101. [Debug diagnostics](M02-evidence/rust-debug-supplemental-supplemental_smart_pointer_projected_base.log), [release diagnostics](M02-evidence/rust-release-supplemental-supplemental_smart_pointer_projected_base.log).

### 2. Sized erasure accepts an unrelated non-Send owner as Send

`tests/m02-api/erasure_sized_type_safety.rs:22–27` constructs `SkSp<Target>` from unrelated `Unrelated { Rc<()> }` through safe `sk_make_sp_as`, then satisfies `requires_send`. Expected: compile rejection, because the actual owner is neither Target nor Send. Actual: **rustc exits 0 in debug and release**, so the expected-rejection contract fails. This program is compiled only, never executed or sent between threads.

Production location: `src/ref_cnt.rs:519`, generic `sk_make_sp_as<U,T>` imposes no relationship between U and T; sized SkSp auto-trait checks consider U while hiding actual T. Restricting Send to sized targets repaired the earlier unsized negative but leaves this sized route open. This is a Rust-specific supplemental type-safety contract; there is no directly corresponding upstream assertion.

Reproduce both profiles with:

```sh
python3 tests/reference/check_m02_api.py
```

Driver exits 1. Exact per-profile rustc commands/exit codes: [debug](M02-evidence/api-debug-erasure_sized_type_safety.log), [release](M02-evidence/api-release-erasure_sized_type_safety.log), [API summary](M02-evidence/api-summary.json). Cow, polymorphic and ordinary probes compile/run successfully; the older unsized negative fails compilation as required. Negative units are not included in runtime counts.
