## Production fixes during acceptance

Fixed in production only (no assertion, expected value, tolerance, fixture or exclusion changed):

1. `src/sk_to.rs`: `sk_to_*` now assert in debug and static-cast in release, matching C++ `SkTo`.
2. `src/scalar.rs`: `scalar_pin` now uses C++ `SkTPin` semantics (`std::max(lo, std::min(x,hi))`), returning `lo` for NaN.
3. `src/stream.rs`: `SkMemoryStream::peek` implemented (default `peek` now returns 0 like C++); `SkMemoryStream::duplicate` resets to offset 0 and `fork` keeps the current offset; `SkFILEStream::from_file` records the initial file position as `start`; `SkDynamicMemoryWStream::read` uses overflow-safe bounds.
4. `src/containers.rs`: `STArray::empty` inherent method added (avoids recursive trait resolution).
5. `src/extras.rs`: Clippy `-D warnings` cleanups (elided lifetimes, `iter_mut`, identity map).
